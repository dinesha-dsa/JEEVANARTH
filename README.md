# JEEVANARTH | जीवनार्थ

**Life Independence Decision-Support System**

JEEVANARTH is a privacy-first, bilingual (English/Marathi), browser-based educational simulator for exploring household cash flow, debt, education goals, retirement readiness, longevity scenarios, human capital and broader life-independence preparedness.

## Key features
- Guided, plain-language life discovery flow
- English / Marathi interface
- Detailed expense classification
- Debt and emergency-resilience modelling
- Education goal projection
- Retirement accumulation and drawdown model
- Second-career / human-capital modelling
- Income-vs-expense and corpus charts
- Life Pressure Map and experimental Life Independence Index (JLI)
- Lower-return and higher-inflation stress tests
- Minimum Effective Change (MEC) option comparisons
- Rule-based expert-style guidance with reasons and expected effects
- Personalised print/PDF report
- Static and privacy-first: entered data is processed in the browser

## Run locally
Open `index.html` in any modern browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `README.md`, and `LICENSE`.
3. Commit the files.
4. In repository **Settings → Pages**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public Pages address after deployment.

## Important limitations
JEEVANARTH is an educational decision-support prototype, not regulated financial, investment, tax, legal, medical, actuarial, or insurance advice. It uses deterministic assumptions and sensitivity scenarios. Returns, inflation, income, health costs, and longevity are uncertain. The experimental JLI is not a validated clinical, actuarial, or investment score.

## Privacy
This release is a static application. It does not transmit entered personal data to a server. Browser-local storage is used only when the user explicitly chooses the local-save function.

## Research / validation roadmap
Future research versions may add validated scoring weights, Monte Carlo simulation, tax-aware modelling, multi-child goal objects, surviving-spouse analysis, calibrated healthcare shocks, accessibility testing, and formal usability/financial-literacy validation.
