# Privacy Baseline — JEEVANARTH v1.0.0

## Public-release position

JEEVANARTH v1.0.0 is described as a static browser application. User-entered information is intended to be processed locally in the browser and not transmitted to a JEEVANARTH backend server.

## Data minimisation

The application should request only information needed for its decision-support functions. Personal fields should have an explicit purpose.

## Local storage

If optional browser local storage is used for profile saving:
- users should be told that data may persist on that device/browser;
- shared/public computers should be treated cautiously;
- users should have a clear way to overwrite or clear locally saved data where implemented.

## Third-party services

Any future addition of analytics, forms, cloud databases, authentication, advertising, telemetry, external APIs, or embedded third-party scripts changes the privacy model and requires this document and the user-facing notice to be revised before deployment.

## Feedback-study privacy

A future pilot feedback form should be kept logically separate from the financial/life inputs unless linkage is scientifically necessary and ethically approved. Collect the minimum research data needed.

## Security boundary

“Local processing” does not guarantee security of the user's device, browser, extensions, downloaded PDFs, screenshots, or locally stored files. JEEVANARTH should not claim absolute confidentiality.
